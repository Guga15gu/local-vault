Privacy Policy — Local Vault

Last updated: 2026-11-06

Local Vault is a personal application with a single user (the owner). This policy describes all data handling performed by the app.

Google Drive access

  • Restricted drive.file OAuth scope: the app can only see, edit, create and delete files that it created itself. No other file in the Drive account is read or modified.
  • Synced files travel only between the owner's device and the owner's own Google Drive. Nothing is sent to third parties.

Local storage

  • Usage data (progress, notes) lives in a local SQLite database on the owner's device only.
  • No telemetry, no analytics, no advertising, no cookies.

Accounts

The app has no user accounts and no public server. Authorization is granted once, by the owner, for the owner's own Google account.

Revoking access

At any time, at myaccount.google.com/permissions (“Local Vault”).

Contact

Use the support e-mail shown on the app's authorization screen.
